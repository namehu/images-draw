# 界面约定

以用户提供的 ChatGPT Images 截图为视觉参考：白色背景、大留白、图片主导的五列卡片、浅灰胶囊标签、底部悬浮输入栏、黑色主操作、左右分栏详情弹窗。独立品牌“图像”，不使用 OpenAI 标志，不宣称官方产品。

- Vue 3；图标统一使用 Lucide；系统字体本地渲染，不引入外部字体或跟踪脚本。
- 桌面 5 列，1150px 以下 4 列，850px 以下 3 列，600px 以下 2 列。卡片 4:5。
- 主要文字 #1a1a1a，背景 #ffffff，弱背景 #f4f4f4，边框 #e9e9e9。圆角卡片 20px，弹窗 28px。
- 使用浏览器原生 dialog 管理焦点和 Escape；原生 select 保留键盘与手机操作。
- 尊重 reduced-motion；加载只显示实际等待时间，不虚构百分比；需要用户输入的错误就近显示。
- 设计参考技能：ui-ux-pro-max 的极简风格与可访问性规则；用户白色参考优先于通用搜索结果中的深色配色推荐。
