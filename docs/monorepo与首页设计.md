# pnpm workspace 与首页设计记录

日期：2026-11-06（北京时间）。

## 为什么采用 monorepo

仓库同时交付两种页面：绘图页构建为静态站点，首页构建为后台配置可粘贴的 HTML。它们共用视觉风格和域名，但有不同的发布流程。pnpm workspace 可以分别构建、统一锁定依赖，不需要额外的任务调度工具。

原 Vue 项目移到 `apps/draw`，新首页放 `apps/home`。原 `docs` 留在根目录，原绘图部署脚本移至 `apps/draw/deploy`。`.git`、仓库远程地址、根目录 `.env.test.local` 保留。

安装工具沿用本机已有 pnpm 8.15.9；直接依赖使用原 npm 锁文件中的确切版本，减少迁移带来的无关版本变化。`pnpm-lock.yaml` 成为唯一依赖锁文件。绘图产物文件名与迁移前一致，业务代码没有因迁移而改变。

## 路径变化

| 原路径 | 新路径 |
|---|---|
| `src`、`public`、`tests` | `apps/draw/` 下同名目录 |
| Vite、TypeScript、Vitest、Playwright 配置 | `apps/draw/` 下同名文件 |
| `scripts`、`deploy` | `apps/draw/scripts`、`apps/draw/deploy` |
| `dist` | `apps/draw/dist` |
| `docs` | 保持根目录 |
| `.env.local`、`.env.test.local` | 保持根目录 |

绘图页 Vite 的 `envDir` 和开发代理变量读取路径已调整到仓库根目录。浏览器脚本从声明过的 `@playwright/test` 导入 Chromium，避免依赖 npm 偶然扁平化提供的传递依赖。

## 首页设计依据

使用 ui-ux-pro-max 的 AI 工具页面推荐：主介绍、能力示意、功能说明和行动入口。配色与字体以用户已经认可的绘图页为优先：保留黑白灰与系统字体，未采用检索结果中的紫色主色或外部字体。

- 基础：白色背景、`#1a1a1a` 正文、`#666` 次级文字、`#e8e8e8` 细边框。
- 宽度：桌面主体最大 1200px；手机 20px 边距。
- 形状：卡片约 20–28px 圆角；主按钮黑底胶囊形。
- 内容：左右主视觉、三张功能卡片、Codex/GPT Image 两项支持能力；不增加未经核实的 SLA、延迟、价格或其他模型。
- 无障碍：语义标题、图片替代文字、装饰 SVG 隐藏、键盘焦点、跳转到正文链接、减少动态偏好。
- 集成：全部 CSS 限定于 `#vn-home`，不改动宿主其他页面；HTML 不含脚本。
- 动效：仅轻微悬停反馈；无自动播放、轮播或虚假进度。

验证包含绘图页已有回归，以及首页在真实 sub2api 页面容器内的桌面、375px 手机、平板、横屏、宿主深色类和键盘导航检查。浏览器测试仅覆盖本地响应，不改变远端配置。
