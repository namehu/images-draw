# Sub2API v0.2.20 核对与绘图页质量设置

日期：2026-11-07（北京时间）

## 结论

v0.2.20 确实增加了 GPT Image 2.6 原生图片链路，也修复了流式编辑收到完整 JSON 时的处理问题。后者与此前“流式失败、非流式成功”的现象相符，但没有升级后的同条件真实请求，不能把之前两次上游 502 的根因确定为这一项。

绘图页不能切换质量是前端第一版固定 `quality: auto` 造成的，不是平台不支持。第一版为了简化小白操作，只开放了模型和比例；本次补齐质量选择，并保留自动作为默认值。

适配开发阶段只读取公开源码、读取测试 Key 的模型列表并修改本地仓库。用户随后明确授权仅更新 `/draw/` 静态文件，已于 2026-11-07 19:58（北京时间）通过 SSH 备份并发布。没有修改 Nginx、sub2api 配置或数据库，没有发起收费图片请求。

## 发布内容与本站影响

| 更新 | 核对结果 | 对本站的处理建议 |
|---|---|---|
| GPT Image 2.6 | 新增 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`；OAuth/setup-token 使用 Codex 原生 Images 端点；2.6 不回退到可能忽略图片模型的 Responses 桥接 | 绘图页从 `/v1/models` 动态获取模型，无需把模型写死。若有显式账号模型映射/分组白名单，应在后台加入新模型 |
| 流式编辑 JSON 兼容 | 上游收到 `stream=true` 却返回完整 JSON 时，网关转换成 `image_edit.completed` 事件，并保留 usage | 当前 `/draw/` 的编辑继续使用已验证的 `stream=false`；不必为了升级强制切回流式。确认新版本真实流式编辑可用后再调整 |
| complexity | 原生生成、JSON 编辑、multipart 编辑均保留显式 `low/medium/high`；省略时不注入默认值 | 本次为 2.6 增加独立“创作复杂度”选择；“模型默认”不发送该字段 |
| 原生编辑及输出参数 | 增加 markup、GIF 帧控制、SVG author 参数的传递 | 本站当前为单参考图、PNG 下载，不需要同时增加标注编辑、动图和 SVG 功能；转发支持也不等于上游账号一定能使用 |
| 1K/2K/4K 账号分流 | 根据尺寸档位选择账号并修复溢出选号的粘性绑定 | 属于像素尺寸/账号路由，与 `quality` 是不同参数。本次未增加 2K/4K 尺寸，也无需为质量切换修改分流配置 |
| 异步生图 503 | 修复异步任务请求体内存预算过早释放 | 本站直接调用 `/v1/images/generations` 与 `/v1/images/edits`，未使用异步任务 API |
| 网关内存与超时 | 默认请求体总预算 1 GiB；新增请求体读取、下游写超时，默认各 120 秒 | 未检查服务器实际配置，不能判断是否需调整。出现对应 408/503 或慢连接问题时再按日志诊断；不因升级直接放大限制 |

注意：2.6 图片支持这一项不需要新增环境变量；整个 v0.2.20 版本仍含管理 MCP 的数据库迁移，不应将两者混淆。

## 当前模型可见性

使用已授权的测试 Key 执行一次只读 `GET /v1/models`，HTTP 200 返回的图片模型为：

- `gpt-image-2`
- `gpt-image-2.5-flare`
- `gpt-image-2.5-sunburst`

这说明该 Key 目前看不到 2.6，不能仅凭列表确定是白名单、映射、账号可用模型还是缓存所致。依据上游升级说明，优先检查后台已有的账号模型映射和分组白名单。后台放行后，在绘图页重新“连接并验证”或刷新，让列表重新获取。不要只在前端硬加模型名。

## 本次本地修改

- 输入栏“设置 · 当前档位”→“图片质量”。提供自动、低、中、高；Image 2/2.5/2.6 另提供超高和最高。
- 六个显示值分别对应 `auto/low/medium/high/xhigh/max`；高档位按模型/账号实际支持情况处理，用量按平台规则计算。本次验证的是正确传参，没有对所有模型档位逐个进行收费实测。
- 文生图 JSON 和参考图编辑 multipart 请求均发送用户选择的 `quality`，不再硬编码自动。
- Image 2.6 单独显示“创作复杂度”。切回旧模型时移除该参数；从高阶质量切到旧模型不支持的档位时恢复自动。
- 本机作品记录保存模型、质量和复杂度，详情显示所用档位。复用作品时恢复这些选择；旧历史缺少新字段时按自动处理。
- 保留每次一张、PNG 输出、原有比例尺寸映射，以及失败后不自动重试的行为。
- 编辑默认仍为非流式；文字生成仍为流式。旧修复文档是当时的实测记录，仍有参考价值。

代码位于 `apps/draw/src/App.vue`、`src/lib/api.ts`、`src/lib/image-options.ts`、`src/lib/history.ts`、`src/types.ts` 与 `src/style.css`。首页代码无修改。
