# 自定义首页配置说明

## 能否直接粘贴

可以。已核对 sub2api v0.2.19 的 `frontend/src/views/HomeView.vue`：

- “首页内容”对应字段 `home_content`；非空 HTML 使用 `v-html` 渲染。
- 以 `http://` 或 `https://` 开头的值会被当作 iframe 地址。
- 自定义内容会替换整张默认首页，包括默认页头。因此本版已包含站点名、导航和登录入口。

本版采用 HTML＋CSS，无 JavaScript、事件处理器和外部字体依赖。普通链接与页内锚点即可完成导航，适用于 `v-html` 插入场景。

源码依据：https://github.com/Wei-Shaw/sub2api/blob/v0.2.19/frontend/src/views/HomeView.vue

## 配置步骤

1. 本地在仓库根目录执行 `pnpm build:home`。
2. 用文本编辑器打开 `apps/home/dist/home-content.html`，复制全部内容。交付包里的“首页配置-直接粘贴.txt”与它相同。
3. 在管理后台的设置页找到“首页内容”，先把当前内容备份到本地，再粘贴代码并保存。
4. 打开或刷新 https://sub.velunest.top/home ，检查“登录”“立即开始”“打开绘图”。
5. 要恢复默认首页，清空“首页内容”并保存；若此前有其他自定义首页，粘贴备份内容恢复。

不要复制 Markdown 的三个反引号，也不要只粘贴预览文件路径。本次没有代为保存后台设置，线上首页仍由你手动切换。

## 文件与预览

- `apps/home/home-content.html`：唯一编辑源。
- `apps/home/dist/home-content.html`：直接粘贴的 HTML 片段。
- `apps/home/dist/index.html`：完整 HTML 预览，可双击打开；也可执行 `pnpm dev:home`，访问 http://127.0.0.1:5174 。
- `apps/home/test-results/`：真实 sub2api 容器环境的浏览器预览截图及检查记录。测试只在隔离浏览器里替换公开设置响应，不会保存设置。

## 视觉与内容

沿用绘图页的白底、黑色圆角按钮、细灰边框和留白。保留原首页的页头、左右主视觉、三项说明和支持能力区，只展示 Codex 与 GPT Image。站点名保留现有 `Sub2API`，以后可在 HTML 中统一替换。

自定义模式不保留默认页的语言和主题按钮。当前版本是完整中文浅色首页，即使宿主处于深色模式也保持白底；这是为了与绘图页保持一致。它不改变登录页、控制台或其他页面的主题设置。

按钮直接链接到本站 `/login`、`/draw/`；页内“支持能力”跳转至对应区块。首页展示不执行模型调用，不需要 API Key。

示例图复用已部署的两个资源：

- https://sub.velunest.top/draw/templates/interior.webp
- https://sub.velunest.top/draw/templates/product.webp

它们来自此前绘图页的演示素材；应保持可访问，或将 `img src` 换成自己的图片地址。预览需联网加载这两张图。更换域名时，同时更新 HTML 内的导航和图片 URL。

## 无需服务器操作

首页配置通过平台自带功能生效，不需要修改 Nginx、数据库表、Docker 或 Cloudflare。此次制作及 monorepo 迁移只修改本地仓库和交付文件，没有操作 DBX 或 SSH 服务器。
